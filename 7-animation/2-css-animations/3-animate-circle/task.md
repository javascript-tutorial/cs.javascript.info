# Animovaný kruh

Vytvořte funkci `zobrazKruh(cx, cy, poloměr)`, která zobrazí animovaný zvětšující se kruh.

- `cx,cy` jsou okenní souřadnice středu kruhu,
- `radius` je poloměr kruhu.
